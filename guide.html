학생 개인 사용법 · 수업 활용법 · 교사 사용법

이 프로그램은 직업을 판정하지 않습니다. 학생이 실제 경험에서 행동과 관심을 발견하고, 작은 진로 실험과 탐구 질문으로 연결하도록 돕습니다.

공통 원칙 이름·학번·학교명·연락처·주소·친구·교사·가족의 실명, 건강·상담·가정형편 등 민감한 정보는 입력하지 않습니다.

PART 1

학생 개인 사용법

휴대전화·태블릿·컴퓨터에서 로그인 없이 사용할 수 있습니다.

경험 찾기
직무 탐색
미니 실험
탐구·로드맵
  1. 접속하고 기기 유형을 고릅니다.
    학교 컴퓨터실이면 ‘공용 기기’, 자신의 휴대전화나 노트북이면 ‘개인 기기’를 선택합니다.
  2. 현재 진로 상태와 실제 경험 3개를 적습니다.
    수업·수행평가·동아리·취미·게임·운동·친구를 도운 일처럼 작은 경험도 괜찮습니다. 경험마다 상황, 내가 한 행동, 결과, 재미있거나 힘들었던 점을 적습니다.
  3. 경험 속 행동을 직접 선택합니다.
    조사·비교·분석·정리·설계·제작·설명·표현·설득·도움·조정·수정 중 실제로 했던 행동을 고릅니다. ‘잘한 것’과 ‘좋아한 것’을 따로 확인합니다.
  4. 직무 행동·관심 대상·환경과 직업 카드를 비교합니다.
    직업의 순위나 적합도 점수가 아니라, 먼저 볼 후보·인접 후보·의외의 후보·환경 비교 후보를 살펴봅니다. 관련 과목은 ‘필수 과목’이 아니라 상담용 참고입니다.
  5. 학교 안에서 해볼 미니 실험 하나를 고릅니다.
    가능한 시간, 개인·모둠, 비용, 결과물 형태를 선택합니다. 인터뷰·설문처럼 다른 사람이 참여하면 먼저 담당교사와 상의합니다.
  6. 활동 후 성찰하고 진로 가설 카드를 완성합니다.
    재미있었던 점, 힘들었던 점, 피드백 후 바꾼 점, 다시 해보고 싶은지를 기록합니다. 계획대로 끝내지 못해도 배운 점을 남기면 됩니다.
  7. 질문 만들기 → 탐구 설계 → 성장 로드맵으로 이어갑니다.
    진로 실험에서 생긴 궁금증을 질문으로 바꾸고, 자료와 방법을 정한 뒤 고1·고2·고3 성장 계획으로 연결합니다.

완료 후 꼭 할 일

  • 진로 가설 요약을 복사하거나 인쇄하기
  • 필요하면 익명 결과 파일 저장하기
  • 공용 기기에서는 ‘이 기기에서 삭제’ 누르기
  • 브라우저를 닫기 전에 저장 여부 확인하기

주의할 점

  • 결과를 적성검사나 합격 가능성으로 해석하지 않기
  • 실제로 하지 않은 활동을 한 것처럼 적지 않기
  • 무료 AI는 선택 사항이며 개인정보를 복사하지 않기
  • 과목 선택은 학교 교육과정 안내와 상담 후 결정하기
진로 실험실 시작질문 만들기로 이동

PART 2

수업으로 활용하는 방법

권장 운영은 4차시 수업과 1~4주의 후속 미니 실험입니다.

차시수업 목표학생 활동산출물
1차시
경험과 행동		자신의 실제 경험을 행동 언어로 설명함개인정보 안내 → 경험 3개 작성 → 행동 카드 선택 → 흥미·결과 구분경험–행동 지도
2차시
직무 세계		직업명보다 직무와 환경을 비교함행동 가설 확인 → 관심 대상·환경 선택 → 직업 카드 4유형 비교 → 과목 연계 참고직무·직업군 탐색 카드
3차시
미니 실험		학교 안에서 실행 가능한 작은 활동을 설계함시간·비용·도구 조건 선택 → 활동 3개 비교 → 하나 선택 → 완료 기준·피드백 작성미니 실험 계획서
4차시
탐구 연결		진로 실험을 탐구 질문과 계획으로 발전시킴질문 후보 생성 → 다섯 가지 가위로 범위 축소 → 자료·방법·윤리 점검 → 성장 로드맵탐구 질문·설계서·로드맵
후속
1~4주		실제 실행과 피드백을 통해 진로 가설을 갱신함활동 수행 → 피드백 수집 → 수정 → 성찰 → 유지·확대·보류·변경 판단성찰 기록과 갱신된 진로 가설

수업 시작 전

  • 학생 기기와 인터넷 접속 확인
  • 네 개 페이지가 모두 열리는지 확인
  • 공용 기기 사용 학생에게 삭제 방법 안내
  • 미니 실험의 허용 범위와 교사 승인 기준 정하기
  • 종이 백업 활동지 또는 화면 캡처 준비

수업 중 교사의 핵심 역할

  • 추상적인 답을 실제 행동으로 바꾸어 묻기
  • 학생이 AI·프로그램 해석을 거부하거나 수정할 수 있게 하기
  • 직업 카드의 장점뿐 아니라 어려움도 보게 하기
  • 미니 실험이 시간·비용·안전 조건에 맞는지 확인하기
  • 결과보다 피드백과 수정 과정을 관찰하기
수업 운영 팁
한 차시에 모든 학생이 같은 화면까지 도달하도록 강요하지 않습니다. 경험 작성이 어려운 학생은 경험 1개를 자세히 완성하고, 진로가 비교적 분명한 학생은 직업의 실제 업무와 미니 실험 검증에 더 시간을 쓰게 합니다.

PART 3

교사 사용법

개별 학생의 전체 서술을 수집하지 않고, 학생이 선택한 익명 구조화 결과만 활용합니다.

개별 상담

  1. 학생이 저장하거나 인쇄한 진로 가설 카드를 확인합니다.
  2. ‘반복 행동의 근거가 무엇인지’, ‘직무의 어려움도 감수할 수 있는지’를 묻습니다.
  3. 미니 실험의 실행 가능성, 안전, 대상자 동의를 확인합니다.
  4. 활동 후 생각이 어떻게 달라졌는지 근거로 설명하게 합니다.

학급 대시보드

  1. 학생에게 ‘익명 결과 파일 저장’ 또는 ‘익명 제출 코드 복사’를 안내합니다.
  2. 메인 화면의 ‘교사용 학급 대시보드’를 엽니다.
  3. 여러 JSON 파일을 한꺼번에 불러오거나 코드를 붙여넣습니다.
  4. 직무 행동·관심 대상·직업·과목·미니 실험·최종 판단 분포를 확인합니다.
  5. 학급 비교 JSON 또는 CSV를 저장하고, 사용 후 교사 기기의 집계 자료를 삭제합니다.

학급 비교 자료 배포

  • 학급 대시보드에서 학생용 비교 JSON 생성
  • 반별 파일을 학생에게 배포
  • 학생은 ‘학급 비교 자료’ 버튼에서 불러오기
  • 등수·우열이 아닌 선택의 다양성 확인용으로 설명
  • 표본이 너무 적은 반은 비교 자료를 배포하지 않기

선배 사례 갤러리

  • 기본 사례는 모두 가상 예시임을 설명
  • 실제 사례는 학생·보호자 동의와 학교 검토 후 사용
  • 실명·학번·사진·상담·가정정보 제거
  • 활동, 결과물, 피드백, 수정, 성찰 중심으로 작성
  • 진학 결과를 활동의 우수성 근거로 과도하게 사용하지 않기

교사가 관찰할 핵심 행동

생활기록 및 상담 활용 원칙

  • 프로그램이 만든 문장을 학생부 사실로 바로 사용하지 않습니다.
  • 계획만 세운 활동을 실제 수행한 것처럼 기록하지 않습니다.
  • 교사가 실제로 관찰하거나 결과물·과정 기록으로 확인한 내용만 참고합니다.
  • 진로 가설은 학생 평가가 아니라 다음 질문과 활동을 정하는 자료로 사용합니다.
  • 선택과목 태그는 합격 유불리 판정이 아니라 상담의 출발점으로 사용합니다.

FAQ

자주 묻는 질문

학생이 경험 3개를 떠올리지 못하면 어떻게 하나요?

최근 한 달의 수업·모둠활동·취미·게임·운동으로 범위를 좁히고, 짝 인터뷰를 활용합니다. 3개를 억지로 채우기보다 경험 1개를 구체적으로 완성하는 것이 낫습니다.

직업 카드에서 나온 직업을 진로로 정해야 하나요?

아닙니다. 직업 카드는 직무 행동과 환경을 비교하기 위한 후보입니다. 작은 활동으로 일부 직무를 직접 해본 뒤 판단을 유지·확대·보류·변경합니다.

휴대전화에서도 사용할 수 있나요?

가능합니다. 다만 긴 경험 작성과 탐구 설계는 화면이 큰 태블릿이나 컴퓨터가 더 편합니다.

인터넷이 끊기면 어떻게 하나요?

페이지가 이미 열려 있다면 일부 작업은 계속 가능하지만 새로고침이나 페이지 이동에서 문제가 생길 수 있습니다. 수업 전 접속을 확인하고 종이 백업지를 준비하는 것이 안전합니다.

학생 결과를 교사가 자동으로 볼 수 있나요?

아닙니다. 서버가 없으므로 자동 수집되지 않습니다. 학생이 익명 결과 파일이나 코드를 직접 제출한 경우에만 교사가 학급 대시보드에서 집계할 수 있습니다.
