# 나의 경험에서 시작하는 진로 실험실 v2.1

고등학교 1학년을 위한 API·서버 없는 정적 진로 탐색 프로그램입니다.

## 핵심 흐름

1. 경험 찾기
2. 경험 속 행동 발견
3. 직무·직업·과목 탐색
4. 학교 안 미니 실험 설계
5. 활동 후 성찰과 탐구 질문 연결

이 프로그램은 적성검사나 직업 판정 도구가 아닙니다. 학생의 실제 경험에서 행동 가설을 만들고, 작은 활동으로 직접 확인하도록 돕습니다.

## 실행 방법

압축을 풀고 `career-lab` 폴더 전체를 GitHub 저장소에 올리거나, 로컬 웹서버에서 `index.html`을 실행합니다.

- GitHub Pages: 폴더 구조를 유지한 채 업로드
- 로컬 테스트: 폴더 상위에서 `python -m http.server 8000`
- 단순 더블클릭 실행도 가능하지만, 브라우저 보안 정책 때문에 클립보드·파일 연결 기능이 제한될 수 있습니다.


## v2.1 최종 보완

- `먼저 살펴볼 후보`는 내부 점수 상위 8개 안에서만 순환합니다. 직업 수를 변경해도 하드코딩된 47이 아니라 실제 데이터 길이를 사용합니다.
- 이름으로 오인할 수 있는 일반 문장은 경고만 표시하고 진행을 막지 않습니다. 전화번호·이메일·주민등록번호·상세주소·학번·민감정보처럼 명확한 패턴만 차단합니다.
- 학급 JSON을 여러 개 불러올 때 깨진 파일은 파일명을 표시하고 나머지 정상 파일은 계속 처리합니다.
- 선배 사례 JSON은 허용된 `action` 값과 `targets` 값을 검증하며, 잘못된 항목 번호를 안내합니다.
- 인쇄 CSS에 A4 용지 크기와 여백을 명시했습니다. 실제 학교 PC의 Chrome/Edge 인쇄 미리보기에서 배율 100%, 머리글·바닥글 해제로 최종 확인하세요.

## 학급 대시보드 사용법

서버가 없으므로 학생 결과가 자동 수집되지는 않습니다.

1. 학생이 STEP 5에서 `익명 결과 파일 저장`을 누릅니다.
2. 학생은 생성된 JSON 파일을 학교 LMS나 교사가 정한 방법으로 제출합니다.
3. 교사는 상단의 `교사용 학급 대시보드`에서 여러 JSON 파일을 한 번에 불러옵니다.
4. 대시보드에서 직무 행동, 관심 대상, 직업, 미니 실험, 과목, 최종 판단의 익명 분포를 확인합니다.
5. `학생용 학급 비교 파일 저장`을 눌러 집계 파일을 생성합니다.
6. 학생은 상단의 `학급 비교 자료`에서 해당 파일을 불러옵니다.

학생용 비교 파일에는 개별 학생 기록이나 자유서술 내용이 들어가지 않고 항목별 인원 집계만 들어갑니다.

## 선배 사례 갤러리

기본 갤러리는 모두 `가상 예시`로 표시됩니다. 실제 학교 사례를 추가할 때는 교사용 대시보드의 갤러리 관리 기능을 사용합니다.

승인 사례 JSON 예시:

```json
[
  {
    "title": "학급 설문 데이터 시각화",
    "action": "analyze",
    "targets": ["data", "society"],
    "duration": "1주",
    "summary": "익명 설문 결과를 표와 그래프로 정리함.",
    "result": "그래프 3개와 해석문",
    "reflection": "질문을 공정하게 만드는 일이 중요했음을 알게 됨."
  }
]
```

실명, 학번, 학급, 사진, 구체적인 개인 사정은 넣지 마십시오. 학교 기준에 따른 활용 동의와 익명 검수를 거친 사례만 사용해야 합니다.

## 자동 선택과목 탐색

`js/data.js`의 `courseCatalog`에서 과목명, 영역, 직무 행동, 관심 대상 태그를 관리합니다.

현재 목록은 2022 개정 교육과정 취지를 참고한 탐색용 예시이며, 실제 학교 개설 과목과 과목명은 학교 교육과정 편성표를 기준으로 수정해야 합니다. 프로그램은 필수 과목이나 합격에 유리한 과목을 판정하지 않습니다.

## 직업 정보 관리

`js/data.js`의 각 직업 카드에는 다음 정보가 있습니다.

- 직업명
- 주요 직무 행동
- 관심 대상
- 업무 환경
- 해결하는 문제
- 실제 업무
- 어려움
- 관련 전공 예시
- 연계 과목 영역
- 동아리 성격
- 정보 상태

학기 시작 전 또는 연 1회 다음을 점검하는 것을 권장합니다.

- 직업명과 업무 설명
- 면허·자격 관련 표현
- 전공 진입 경로
- 학교 개설 선택과목
- 직업 정보 확인 날짜와 출처

공식 교육과정 확인은 국가교육과정정보센터(NCIC), 직업 정보는 커리어넷·고용24 등 공식 자료를 우선 활용하십시오.

## keyword.html 연결

STEP 5의 `탐구 질문 만들기로 이동` 버튼은 기본적으로 같은 폴더의 `keyword.html`을 찾습니다.

연결 데이터는 URL이 아니라 localStorage의 `careerLabBridgeV2`에 JSON으로 저장됩니다.

전달 항목:

- 승인한 관심 행동
- 관심 대상
- 확인해 볼 과목
- 비교 직업
- 미니 실험
- 질문 씨앗
- 아직 불확실한 점
- 실제 핵심 행동
- 피드백 후 수정 내용

기존 `keyword.html`에서 다음처럼 읽을 수 있습니다.

```javascript
const careerBridge = JSON.parse(
  localStorage.getItem('careerLabBridgeV2') || 'null'
);
```

경로가 다른 경우 `js/data.js`의 `config.keywordPath`를 수정합니다.

## 개인정보 원칙

- 이름·학번·학교명 입력란 없음
- 서버 전송 없음
- 자유서술 내용은 익명 학급 결과에 포함하지 않음
- 공용 기기는 sessionStorage 사용
- 공용 기기만 15분 미사용 시 초기화
- 학생이 언제든 현재 작업 삭제 가능
- 자동 탐지는 보조 기능일 뿐 완전한 개인정보 검출을 보장하지 않음
